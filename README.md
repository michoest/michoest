### Michael Oesterle

I build LLM agent systems, and I do research on how to govern multi-agent systems and keep them safe.

Currently Chief AI Officer at [bridgebrAIn](https://www.linkedin.com/company/bridge-brain), where I design the architecture of an LLM agent platform: agent interaction logic, a per-client memory layer, and privacy-compliant processing of sensitive company data. That code is private. What you'll find here is mostly research code.

**Background**
- PhD in Computer Science, University of Mannheim: governing black-box agents by restricting their action spaces instead of reshaping their rewards
- Applied Science Intern at Amazon Research: ICECREAM, coalition-based causal explanations (CLeaR 2025)
- SPAR 2024: how sparse-autoencoder features evolve across the layers of a language model (NeurIPS 2024 ATTRIB workshop)
